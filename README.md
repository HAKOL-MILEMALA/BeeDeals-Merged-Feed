# Bee.Deals – פיד מאוחד

סקריפט Tampermonkey שמוסיף ל-Bee.Deals לשונית **"הכול"**, המאחדת את חמשת מדורי הפיד וממיינת את הפרסומים לפי תאריך הפרסום המקורי.

## התקנה

1. מתקינים את [Tampermonkey](https://www.tampermonkey.net/) בדפדפן.
2. לוחצים על הקישור הבא ומאשרים את התקנת הסקריפט:

   **[התקנה ישירה של Bee.Deals – פיד מאוחד](https://raw.githubusercontent.com/HAKOL-MILEMALA/BeeDeals-Merged-Feed/main/BeeDeals-Merged-Feed.user.js)**

3. נכנסים ל-[Bee.Deals](https://bee.deals/dashboard) ומופיעה לשונית חדשה בשם **"הכול"**.

## עדכונים

הסקריפט מוגדר לבדוק עדכונים דרך GitHub ולהוריד גרסאות חדשות אוטומטית באמצעות Tampermonkey. אין צורך להתקין מחדש בכל עדכון.

## מה הסקריפט עושה?

- מאחד את חמשת מדורי הפיד: הדילים המעודכנים, הדילים החמים, מוח כוורת, עדכונים מהרשת וחדש בכוורת.
- ממיין לפי `targetData.date` בלבד — תאריך העריכה אינו משנה את מיקום הפרסום.
- שומר על תצוגת הכרטיסים המקורית של האתר.
- כפתור "טען עוד" מביא פרסומים נוספים מכל המדורים.
